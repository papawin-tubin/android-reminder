# ตั้งเวลาเตือน (แอป Android ทำงานในเครื่อง)

ผู้สร้าง: MawinIoT · โทร 065-5099395 · v.1
(ข้อความนี้แสดงที่ท้ายหน้าหลักของแอป แตะเพื่อเปิดหน้าโทรออก)

เตือนความจำ **ครั้งเดียว / ทุกวัน / ทุกเดือน** ติดตั้งบนมือถือ Android เครื่องเดียวจบ
ไม่ต้องมีบอร์ด ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องต่ออินเทอร์เน็ต (แอปไม่ขอสิทธิ์อินเทอร์เน็ตเลย)

- ใช้ AlarmManager ของระบบ จึงเตือนได้แม้ปิดแอปและเครื่องหลับ
- เตือนด้วยเสียงนาฬิกาปลุก สั่น และการแจ้งเตือนที่มีปุ่ม **รับทราบ / เลื่อน 5 นาที** (เสียงวนซ้ำจนกดรับทราบ หรือครบ 2 นาที)
- ปิด/เปิดเครื่อง เปลี่ยนเวลา หรืออัปเดตแอปแล้ว ตั้งนาฬิกาปลุกใหม่ให้เอง และถ้ามีรายการที่พลาดไประหว่างนั้นจะเตือนทันทีพร้อมบอกว่าล่าช้าเท่าไร
- แบบ "ทุกวัน" เลือกเฉพาะบางวันในสัปดาห์ได้ (อา. จ. อ. พ. พฤ. ศ. ส.) เช่น จันทร์-พุธ-ศุกร์
- แตะที่รายการเพื่อแก้ไข กดค้างเพื่อลบ
- เดือนที่สั้นกว่าวันที่ตั้ง (เช่น ตั้งวันที่ 31) จะเตือนวันสุดท้ายของเดือน
- ข้อมูลเก็บในที่เก็บส่วนตัวของแอป ไม่มีโฆษณา ไม่มี dependency ภายนอก
- รองรับ Android 8.0 (API 26) ขึ้นไป

## สร้างไฟล์ APK (เลือกทางใดทางหนึ่ง)

### ทาง A: GitHub Actions (ไม่ต้องติดตั้งอะไรบนคอม)

1. สร้าง repository ใหม่บน GitHub (เป็น private ก็ได้) แล้วอัปโหลดทั้งโฟลเดอร์นี้ขึ้นไป
   (ต้องมีโฟลเดอร์ `.github/workflows` ติดไปด้วย)
2. เปิดแท็บ **Actions** → workflow **Build APK** → **Run workflow** (หรือ push เข้าสาขา main ก็รันเอง)
3. รอประมาณ 3-5 นาที เปิดรอบที่รันเสร็จ แล้วดาวน์โหลด artifact ชื่อ **reminder-apk** จะได้ `app-debug.apk`

### ทาง B: Android Studio

1. เปิดโฟลเดอร์นี้ด้วย Android Studio (รุ่นใหม่ ๆ) รอ Gradle sync
2. เมนู **Build → Build Bundle(s)/APK(s) → Build APK(s)**
3. ไฟล์อยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

### ทาง C: บรรทัดคำสั่ง

ต้องมี JDK 17, Android SDK (platform 34) และ Gradle 8.9 ขึ้นไป

```bash
gradle assembleDebug
```

## ติดตั้งบนมือถือ

1. ส่งไฟล์ `app-debug.apk` เข้ามือถือ (สาย USB, Drive, LINE Keep ฯลฯ)
2. แตะไฟล์เพื่อติดตั้ง ถ้าเครื่องถาม ให้อนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก" สำหรับแอปที่ใช้เปิดไฟล์
3. ถ้า Play Protect เตือน (เพราะเป็นแอปที่ไม่ได้มาจาก Play Store) เลือกติดตั้งต่อ

## ตั้งค่าครั้งแรก (สำคัญ ถ้าไม่ทำอาจไม่เตือนตรงเวลา)

เปิดแอปแล้วทำตามแบนเนอร์สีส้มด้านบน (แตะเพื่อไปหน้าตั้งค่า):

1. **อนุญาตการแจ้งเตือน** (Android 13 ขึ้นไป)
2. **สัญญาณปลุกและการเตือน** ให้เตือนตรงเวลา (Android 12/12L)
3. **ไม่จำกัดแบตเตอรี่** ของแอปนี้ แนะนำอย่างยิ่ง
4. เครื่องบางยี่ห้อ (Xiaomi, OPPO, Vivo, Huawei, Samsung) มีการฆ่าแอปพื้นหลังแรงกว่าปกติ
   ให้เปิด "เริ่มอัตโนมัติ" (Autostart) และตั้งแอปเป็น "ไม่จำกัด/ไม่ปรับให้เหมาะสม" ในหน้าตั้งค่าแบตเตอรี่ของเครื่อง
   ดูวิธีเฉพาะรุ่นได้ที่ dontkillmyapp.com

เสียงเตือนใช้เสียงนาฬิกาปลุกของเครื่อง ปรับเสียงได้ที่ ตั้งค่า → แอป → ตั้งเวลาเตือน → การแจ้งเตือน → การเตือน

## ทดสอบตรรกะเวลาบนคอม (ไม่ต้องใช้ Android)

```bash
S=app/src/main/java/app/reminder/local
mkdir -p /tmp/chk && javac -d /tmp/chk $S/Reminder.java $S/Schedule.java check/ScheduleCheck.java
TZ=Asia/Bangkok java -cp /tmp/chk ScheduleCheck
```

ครอบคลุมทุกวัน ทุกเดือน (เดือนสั้น ปีอธิกสุรทิน ข้ามปี) ครั้งเดียว และการตรวจสอบข้อมูล

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `Schedule.java` | คำนวณเวลาเตือนถัดไป (ล้วน ๆ ทดสอบได้) |
| `Alarms.java` | ตั้ง/ยกเลิกนาฬิกาปลุกของระบบ และเตือนรายการที่พลาด |
| `AlarmReceiver.java` | ถึงเวลา: แสดงแจ้งเตือน แล้วตั้งรอบถัดไป |
| `ActionReceiver.java` | ปุ่ม รับทราบ / เลื่อน 5 นาที |
| `BootReceiver.java` | ตั้งนาฬิกาปลุกใหม่หลังเปิดเครื่อง/เปลี่ยนเวลา/อัปเดตแอป |
| `Notifier.java` | ช่องแจ้งเตือน เสียง และข้อความ |
| `Store.java` | เก็บรายการเป็นไฟล์ JSON |
| `MainActivity.java`, `EditActivity.java` | หน้าจอรายการและฟอร์มเพิ่ม/แก้ไข |

## สถานะการทดสอบ

ตรรกะเวลา (`Schedule`) ผ่านการทดสอบรันจริงบน JVM ทั้งเขตเวลา Asia/Bangkok และ America/New_York
ส่วนที่เป็น Android (หน้าจอ การแจ้งเตือน นาฬิกาปลุก) เขียนโดยไม่มี Android SDK ให้คอมไพล์ในขั้นตอนเขียน
บิลด์ครั้งแรกอาจเจอ error เล็กน้อยที่ต้องแก้ ถ้าเจอให้ส่งข้อความ error มา
